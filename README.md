## ℹ️ À propos de CaRevient

Application Flutter de révision de cartes (flashcards) :
- Répétition espacée
- Stockage local
- Gestion des médias (image/audio)
- Sessions de révision, collections filtrées
- Import/export au format et partage entre utilisateurs

Pour la documentation utilisateur complète, consultez le [wiki](https://github.com/Bill-Gudule/carevient_downloads/wiki).
